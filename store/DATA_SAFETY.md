# Google Play「資料安全」表單草稿（Archery Assistant）

> 這是草稿，不是標準答案。Play Console 的題目和說明會更新，送出前請逐題對照當時的說明；有疑問時，寧可選更保守（揭露）的答案。
> 對應的政策頁：`PRIVACY.md`（上架時要填這份的公開網址）。

## 先決條件
- 上架的是 **Google Play 版**（`play` flavor）：沒有檢查更新、沒有「安裝應用」權限，不連 GitHub。
- 唯一的網路用途：使用者主動開啟的**區域網路**分享／匯入／自動尋找（同一個 Wi-Fi 內的 HTTP 與 mDNS）。
- 開發者沒有任何伺服器，也收不到任何資料。

## 逐題建議

| 題目 | 建議答案 | 依據 |
|---|---|---|
| 應用是否蒐集或分享任何必要的使用者資料類型？ | 預期為「否」；若 Console 的定義把「使用者主動在區網內傳給自己另一台裝置」算作分享，就要如實勾選 | 資料不會離開使用者的區域網路，開發者與任何第三方都拿不到。「蒐集」指資料傳到開發者或第三方的伺服器，這裡沒有 |
| 資料是否在傳輸中加密？ | 若表單要求回答：**否**（區網內 HTTP，需 PIN）。如實說明比選「是」安全 | 區網分享用明文 HTTP，由 PIN 與信任裝置保護 |
| 是否提供使用者要求刪除資料的方式？ | 資料只在本機：使用者可在應用內刪除記錄，或解除安裝 | 無伺服器端資料 |
| 是否使用廣告 SDK / 分析 / 第三方追蹤？ | 否 | 專案沒有任何這類相依套件 |
| 是否符合家庭政策 | 不適用（目標受眾為一般用戶，不是兒童專用） | |

## 權限與其用途（可用於 Console 的權限聲明）
| 權限 | 用途 |
|---|---|
| `VIBRATE` | 放箭、滿一趟、疲勞提醒的震動 |
| `WAKE_LOCK` | 設定開啟時，偵測在螢幕熄滅後持續 |
| `INTERNET` | 區域網路分享與匯入（本機網頁伺服器與同網路連線） |
| `ACCESS_WIFI_STATE`、`CHANGE_WIFI_MULTICAST_STATE` | 區網自動尋找（mDNS） |
| ~~`REQUEST_INSTALL_PACKAGES`~~ | **Play 版已移除**（只有 GitHub 版有） |

## 其他要先確認
- `android:usesCleartextTraffic="true"`：區網分享是明文 HTTP。審核可能會問，答案是「僅用於區域網路內使用者自己的裝置之間」。如果之後想更保守，可改成只允許私有網段。
- 內容分級問卷：沒有暴力、賭博、使用者生成內容；功能是運動記錄與動作分析，不是醫療用途，商店文案避免醫療宣稱。
- 目標 API：35，符合目前要求；每年 Google 會調整，送審前再確認一次。
- 新個人帳號需先完成封閉測試（至少 12 位測試者、連續 14 天）才能申請正式版。
